# レシート家計簿

レシートを撮ると、AIが品目ごとにジャンル分けして、月にいくら何に使ったかを集計する家計簿。

- 公開URL（スマホでもPCでも同じURL）: https://claude.ai/artifact/HF58f5dCG6rfH42hQLZeP2
- データ保存先: claude.ai の Artifact データベース（ログインしたアカウントごとに `data/users/<id>/` に保存）。同じアカウントでログインしていれば、どの端末からでも同じデータが見える。
- AI読み取り: Artifact の `sample` 機能（閲覧者の Claude アカウントで実行）。APIキー不要。

## ファイル

- `kakeibo.html` — アプリ本体（1ファイル完結）。

## 更新方法

`kakeibo.html` を編集して、Claude Code で同じURLに再公開する（URLもデータもそのまま）。
